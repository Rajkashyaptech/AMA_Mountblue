# AMA

## What is MVT in Django?
- MVT: Model-View-Template, Django's architecture separating data (Model), logic (View), and presentation (Template).

## Start Project Command in Django?
- `django-admin startproject projectname` — creates a new Django project structure.

## How to Create Element in DOM?
- Use `document.createElement('tag')` to create a new HTML element, then append it with `parent.appendChild(element)`.

## Use of Shell in Django?
- `python manage.py shell` — opens an interactive Python shell with Django models and settings loaded for testing and debugging.

## What is the Client–Server Architecture?
- Client sends requests to server; server processes and responds. Separates user interface (client) from data processing (server).

## What is HTTP?
- HyperText Transfer Protocol: standard for transferring data over the web (requests/responses between client and server).

## What is Authorization?
- Verifying if a user has permission to access resources or perform actions (after authentication).

## What is Django?
- A high-level Python web framework for rapid development of secure, scalable web applications.

## What is MVT Architecture in Django?
- Model: Handles data and database. View: Handles logic and requests. Template: Handles presentation and HTML.

## What is a Django Model?
- A Python class representing a database table; defines fields and methods for data interaction.

## What is Middleware in Django?
- Components that process requests/responses globally (e.g., authentication, logging, CORS) before reaching views.
